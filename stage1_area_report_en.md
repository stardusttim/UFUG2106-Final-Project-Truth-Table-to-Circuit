# Stage 1 Report: Area Optimization Under a Delay Target

## 1. Problem and interface

The input specifies a complete truth table for n inputs and m outputs, the area and delay of AND2, OR2, and NOT gates, and a target delay. The binary row index uses x0 as its most significant bit, and character j of each row gives output yj. The output lists gate definitions in topological order followed by output signal IDs. Signal 0 is constant zero, IDs 1 through n are inputs, and later IDs are gates. Constant one is generated by NOT 0.

The method seeks a correct circuit that meets the delay target while reducing gate area. Delay is the maximum arrival time at any output; area is the sum of the costs of gates actually used. This heuristic does not guarantee a globally optimal circuit or that a feasible circuit will be found for every input.

## 2. Bottom-up Shannon decomposition

For variable x, let L and H be the cofactors for x=0 and x=1:

```text
f = (!x AND L) OR (x AND H)
  = (x OR L) AND (!x OR H)
```

In binary row order, adjacent rows differ only in the last variable. Each truth-table bit is first represented by a constant signal. The algorithm combines adjacent subfunctions as L and H, working from the last variable toward the first until it obtains an output signal. Outputs are constructed individually but share the gate cache. When L=H, it returns L directly. AND and OR construction also simplifies constants and idempotent operations, such as 0 AND a=0, 1 OR a=1, and a AND a=a.

## 3. Candidate construction

**Two multiplexer forms.** Each merge constructs the sum-of-products and product-of-sums forms above, then compares their output arrival times and estimated areas. The forms implement the same selection function but have different gate types and paths.

**Both polarities.** Each subfunction retains one signal for the function and one for its complement. The algorithm decomposes both polarities and compares each direct result with the inversion of the opposite result. This allows later logic to use a faster or estimated smaller polarity. Inversion removes double NOTs and reuses input negations.

**Parallel two-variable expansion.** For adjacent variables y and x, four cofactors correspond to 00, 01, 10, and 11. Shared decoder signals !y!x, !yx, y!x, and yx are each ANDed with the corresponding cofactor; the four terms are ORed. The algorithm checks all three balanced binary OR pairings to account for different arrival times and compares the result with two sequential multiplexers, first on x and then y. It performs the comparison for both polarities. If one variable remains, it performs one two-way merge.

**De Morgan rewriting.** The algorithm also tries `NOT(AND(NOT a, NOT b))` when AND delay plus NOT delay is less than OR delay, or in area-search mode when AND area plus two NOT areas is less than OR area. This condition only generates an alternative; it does not guarantee its actual cost or delay. Candidate signals are compared, and existing inverted signals may be reused.

## 4. Sharing, delay, and area

Gates are structurally hashed by type and input IDs; inputs of AND and OR are sorted so commuted inputs share the same key. The cache is shared across all outputs. Inputs and constant zero have arrival time zero. A gate's arrival time is the maximum arrival time of its inputs plus its own delay; constant one is a NOT gate and therefore has NOT delay. Circuit delay is the maximum output arrival time.

The local area estimate recursively adds a gate's cost to its input subcircuit estimates; inputs and constant zero have estimate zero. This expands a shared DAG as a tree and may count shared gates more than once, so it is only a search heuristic. Actual area is calculated by traversing backwards from all outputs and counting each reachable gate once; unused candidates are excluded.

## 5. Area and delay search

The program tries local tolerances -1, 0, 1, 2, 4, and 8. At -1 it selects the faster result as the baseline. For other values, if the arrival times of two local candidates differ by more than the tolerance, it selects the faster one; otherwise it selects the lower estimated area, breaking ties by arrival time. Local tolerances can accumulate through layers, so they are not a bound on the final path's slack.

Each attempt independently constructs a complete multi-output circuit, then measures its actual area and delay. Once the current best meets the target, it is replaced only by a target-meeting candidate with strictly smaller area. If the current best misses the target, a target-meeting candidate is preferred; otherwise, a faster candidate replaces it. Equal-area feasible candidates leave the current best unchanged. The program marks gates reachable from the outputs, renumbers them in their original topological order, and writes them so each gate references smaller IDs.

When a positive runtime limit is supplied, before each additional attempt the program uses elapsed time, the first construction's duration, and a 30 ms reserve as a heuristic budget. When a positive memory limit is specified, it skips additional search. Baseline construction is not interrupted and memory is not forcibly capped, so these measures do not guarantee resource compliance on every machine or input. Different runtime environments may also lead to different search results.

## 6. Correctness and complexity

Shannon decomposition selects L when x=0 and H when x=1. Exactly one decoder term is true in the two-variable expansion, so it computes the same function. Inversion, De Morgan rewriting, and constant simplification preserve equivalence; sharing identical gates does not change functionality. Inductively, the final outputs implement the input truth table. This argument assumes valid input, no integer overflow, and sufficient resources.

Reading the truth table takes O(m·2^n) time and space. Each construction processes subfunctions at each level for every output and builds several candidate gates. Actual cost depends on sharing and cache size. Up to six constructions are attempted, and the best circuit may coexist with a current candidate, increasing runtime and peak memory.
